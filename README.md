# Clip Barber Studio

Aplicación web para una barbería, con sitio público, reserva de turnos y paneles
de administración y barbero.

## Tecnologías

- HTML, CSS y JavaScript
- Supabase
- Funciones serverless

## Estructura

La aplicación principal se encuentra en `clip Barber/`.

## Uso local

Serví esa carpeta mediante HTTP para conservar el comportamiento de los módulos
y las integraciones del navegador.
